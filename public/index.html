El problema

El cuaderno se moja, se pierde y no saca cuentas

Buena parte de la venta de una ferretería se hace al fiado: el cliente se lleva el material y paga después. Ese control en papel falla siempre por lo mismo.

Antes

Con el cuaderno

  • Nadie sabe de memoria cuánto debe cada cliente hoy.
  • La mora se calcula a ojo, distinto cada vez y según quién atienda.
  • Los abonos parciales se anotan al margen y se pierden.
  • Si el cuaderno se moja o se traspapela, se pierde dinero real.
VS
Ahora

Con Fiados Ferrefacil

  • El saldo de cada cliente sale en pantalla al instante.
  • Los días de atraso los cuenta el sistema, siempre igual.
  • Cada abono queda registrado y baja el saldo solo.
  • Todo vive en una base de datos, no en una hoja suelta.

Cómo funciona

Tres pasos en el mostrador

Igual que con el cuaderno, pero sin las cuentas.

  1. 1

    Registrás el cliente

    Nombre y teléfono bastan. Si querés, le ponés un límite de crédito para no pasarte.

  2. 2

    Anotás el fiado

    Qué se llevó, cuánto y para cuándo lo paga. Ahí queda guardado con su fecha.

  3. 3

    Cobrás y abonás

    Cada pago que entra se registra y baja el saldo. La mora se actualiza sola.
